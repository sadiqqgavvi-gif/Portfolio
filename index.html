Final year project

SmartHire

An AI interview coach. Practice technical, behavioral and situational questions and get every answer scored.

  • Three-tier scoring: the OpenAI API first, then a Python heuristic fallback, then a built-in Node.js evaluator, with guardrails that cap scores for short or off-topic answers.
  • Voice mock interviews with the Web Speech API and a Recharts dashboard for scores and session history.
  • Email and Google sign-in with short-lived JWTs and rotating httpOnly refresh tokens, behind Helmet, CORS and per-route rate limits.
  • Dockerized, with GitHub Actions testing the frontend and backend on every push.

React 19, Tailwind CSS, Node.js, Express 5, MongoDB, OpenAI API, Docker

Chat App

One-on-one and group chat that updates instantly, with no page refresh.

  • Socket.io rooms per user and per chat for instant delivery, typing indicators, online presence and sent, delivered and read receipts.
